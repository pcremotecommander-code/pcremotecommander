COMMUNITY IDEAS

Share a useful prompt.

Help someone get more from their PC. Original submissions are reviewed before publication.

Suggest a prompt ↗Opens GitHub · Keep private data out.

Explore · files

Map an approved folder

Get a useful overview without dumping every filename.

List the top-level contents of my approved project folder. Group files by type, flag unusually large files, and give me the paths of the five items most likely to matter. Read files only if needed for the summary.
Explore · search

Find the right document

Search by topic and return paths for follow-up.

Search my approved workspace for files about [topic]. Return up to ten likely matches with their paths and a one-sentence reason for each. Ask before opening any file outside that workspace.
Explore · status

Check the connection

Find out which computer and abilities are available.

Check which PC Remote Commander computer is selected and online. Summarize its available file, command, browser, and desktop capabilities. Tell me which permission I would need for my next task.
Edit · files

Preview a small change

Review before any file is modified.

In [approved file path], replace [old text] with [new text]. First show a dry run with the exact diff and explain what could be affected. Wait for my approval before writing, then confirm the saved path and backup if one was created.
Edit · organization

Plan a folder cleanup

Make the proposed moves easy to inspect.

Review [approved folder] and propose a simple organization plan. Show a table of current path → proposed path for at most 20 files. Do not move, rename, or delete anything until I approve the specific plan.
Edit · recovery

Review a file backup

Compare the current file with its available backup.

For [approved file path], check whether PC Remote Commander has a backup. Summarize how it differs from the current file. Ask before restoring anything, and tell me the expected result of a restore.
Diagnose · terminal

Understand a failed command

Keep diagnostics narrow and readable.

Review the output of my most recent approved command. Explain the likely failure in plain language, cite the relevant error lines, and suggest one safe next diagnostic command. Ask before running it.
Diagnose · browser

Inspect a page problem

Gather evidence before clicking or submitting.

Inspect the currently open browser page and tell me its title, URL, and visible error or status. Do not type into forms or click submit. Suggest the next step and ask before changing the page.
Diagnose · desktop

Explain what is on screen

Use desktop access only when granted.

If desktop access is available, inspect the current screen and describe the active app and any visible error. Avoid quoting private content unnecessarily. Tell me what you would click next and wait for approval.
