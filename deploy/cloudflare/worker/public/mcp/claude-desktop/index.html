Remote MCP setup

Set up Claude Desktop

Before you beginWindows PC · Node.js 20+ · PCRC account · access to custom MCP connectors for remote setup. For same-PC access, follow the Local MCP guide.

  1. Start and pair your PC

    Run the Windows setup command. Sign in to PCRC, compare the pairing codes, select your computer for AI tools, and leave its terminal Online.

    npx --yes pcremotecommander@beta setup

    Requires Node.js 20+. Windows install help.

  2. Add a custom connector

    In Claude, open Customize → Connectors. Choose Add → Add custom connector. On managed plans an owner may need to add it first.

  3. Enter the URL and sign in

    Name it PC Remote Commander, paste the server URL and continue. Use Sign in now and Claude’s published identity when offered, then complete PCRC OAuth.

  4. Enable it for the conversation

    Click Connect if prompted. Review PCRC consent using the account that owns the online PC. Return to Claude Desktop with the same Claude account. In a chat, open + → Connectors and enable PCRC.

Connection details

Remote MCP server URL

https://pc-remote-commander.pcremotecommander.workers.dev/mcp

For remote access, add PCRC in Claude’s web connector settings using the same Claude account as your desktop app. Then enable it in Claude Desktop.

Where do you want to work?

From another device

Leave PCRC running on your paired Windows PC. Open a compatible assistant on your phone or laptop, authorize PCRC with the same account, and ask about files on the selected PC.

Select your computer

On the same computer

Claude Desktop or Cursor can start PCRC over stdio. Select a workspace on that PC and inspect project files without pairing through the hosted gateway.

Local installation steps

Need help connecting?

The computer is offline or missing

Start PCRC on Windows, keep the terminal open, and select the device on your PCRC dashboard.

Sign-in worked, but the tool list is empty

Check that the account in the PCRC terminal matches the account you used for OAuth. Refresh the server’s tool list in Claude Desktop, then retry the read-only request.

How do I stop access?

Disconnect PCRC in the assistant or revoke the device from your dashboard. Stop the local agent with Ctrl+C.
