What you can do

What can your assistant help you do?

A small agent runs on your PC. PCRC connects it to your AI assistant through MCP, the protocol assistants use to call tools. You choose the computer and approve its access.

FILES

Find and update your files

Ask: “Find the configuration file in my project and show the changes needed.” Search, read, and edit within the permissions you grant.

TERMINAL

Understand command failures

Ask: “Check why my build failed.” Your assistant can inspect command output and propose the next step. Commands require control access.

BROWSER + DESKTOP

Interact with pages and apps

Ask: “Explain the error on this page.” With browser or desktop access enabled, your assistant can inspect the interface and use supported controls.

Why choose PCRC?

Your preferred assistant. Your own computer.

PCRC is the connection and control layer between a compatible AI client and a PC you authorize. Bring your assistant; keep your files, commands and apps on the computer that needs the work.

Work from the chat you already use

Connect a compatible ChatGPT, Claude or Cursor client to your paired Windows PC. For example, ask it to inspect a local test failure and read the result without manually copying command output into chat.

Keep access in one dashboard

Pair your computers, choose which one receives new AI requests, view usage and revoke a device when you are finished. The selected PC must stay online with its agent running.

Build with multiple AI assistants

Split a project: one assistant builds a feature, another writes tests, and a third reviews the result. With beta.35, up to eight active assignments can reserve separate file areas. Conflicting claims wait their turn; assistants check their assignment before continuing and refresh file hashes. Uncertain work requires review before handoff.

Windows setup

Connect your PC in four steps.

Use PowerShell, Command Prompt, or Windows Terminal on the computer you want to connect. Run the setup command below. Python is bundled; if Node.js is missing, use the automatic installer underneath.

npx --yes pcremotecommander@beta setup

If the command above does not work, use this automatic installer. It also prepares Node.js if missing:

powershell -NoProfile -Command "irm https://pc-remote-commander.pcremotecommander.workers.dev/install.ps1 | iex"

Review full computer control on the website: files, commands, browser and desktop. Access starts after your approval.

Good to know

Your access, explained.

What does this website do?

The public dashboard manages your paired computers, selected device, permissions, usage, and plan. Your AI client is where you ask for tasks; the local agent carries them out on your PC.

Does PCRC include an AI model?

No. Bring a compatible MCP client and its required plan. PCRC connects that client to your computer’s tools.

Can I install on Linux?

The public npm beta supports Windows. Linux has a development source setup, but no verified public download yet. See Linux availability and source instructions.

What happens to files and screenshots my assistant reads?

Tool results pass through the gateway to your assistant and may become part of its conversation. See the draft privacy notice for data flow and current limits.

Does the computer need to stay online?

Yes. Keep the Windows agent running and select the computer in your dashboard for remote MCP requests.

Can the assistant change files or run commands?

Only when you grant those capabilities to the computer and authorize the client for control. Sensitive actions may also require a separate approval.

Where do I stop access?

Use your Devices dashboard to stop AI access or revoke the computer. Revoking removes its device key.
